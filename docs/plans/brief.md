# Overview
I want to build a workflow agent my dad can use. It doesn't take much for systems to be complex before the average small business owner can't cope with anymore. We need to work up some small business use cases and start with a blank type slate and some sort of grokkable interaction. Maybe voice maybe type. It should acknowledge their frustration with tech and tell them it understands and AI can and wil help them achieve the fuinctionality they desire. Ask them to think of a chore reducer.Complemeent them on running a business, show  them visuals, the mindset for them is to think outside the box. Bring problems we will work toegether to find opportunities to fix them

## What the app should do.
* Listen for problems.
* Be super simple.
* Ability to explain everything in the app.
* Build the app dynamically
* Connect to Google and Meta
* Look fun and easy to use.
## Expected Use Cases
* Help me build standard email replies
* Build a CRM
* Build a booking system
* Build a workflow to handle a use case.
* Help me use free software
* Build me a dashbaord

## Foundational Features
* Oauth apps in major providers to connect to data.
* Be able to dynamically find and load skills, mcps and agents.
* Secure the customers data.
* It should manage it's own datastore and database deisgn.
* It should manage auth for under 20 people.
* It should know the timezone
* It shuld have triggers, workflow data access.
* Take an opioniong ona beautiful UI / UX framework and use that.
* Shuld be themeable.
* The app is an App but can be interacted with using an Agent. Think ClickOps in a SaaS app or use the Agent to do it.
* Focus on desktop only for now.
## User Goals:
* Support business knowledge.
* Support business state
* Support business workflows.
* Be clear on why something happened.
* AI available to build the app and query its data.
